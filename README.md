# Bankist

A minimal banking landing page built with vanilla HTML, CSS, and JavaScript.

## Overview

`Bankist` is a modern marketing-style landing page for a fictional digital bank. It highlights core banking features, operations, customer testimonials, and includes interactive UI behavior such as smooth scrolling, a modal sign-up form, tabbed content, and mobile navigation.

## Features

- **Responsive landing page layout** (desktop-first design)
- **Smooth scroll navigation** for section links and the hero CTA button
- **Modal account sign-up form** with open/close interaction and Escape-key support
- **Tabbed operations section** for instant transfers, loans, and account closing
- **Navigation hover interaction** and visual active states
- **Lazy image placeholder styling** for hero and feature images
- **Mobile menu support** with a hamburger toggle and mobile navigation links
- **Modern minimalist design** with clean cards, icons, and accent gradients

## Files

- `index.html` — main page markup
- `new-style.css` — primary project styling
- `index.js` — interactive behavior for modal, scrolling, tabs, and navigation
- `img/` — image assets used throughout the site

## Live Demo

Visit the deployed landing page at: https://bankist-bank-landing.netlify.app/

## How to use

1. Open `index.html` in a browser.
2. Click the navigation links or the "Learn more" button to jump to page sections.
3. Click "Open account" to display the modal sign-up form.
4. Use the operations tabs to switch between service descriptions.

## Notes

- The page is built without a build toolchain.
- Images are included in the `img/` folder and loaded directly from HTML.
- The footer credits the original design inspiration and usage guidance.
